    About This Project

    FlowRate is a polished currency conversion app focused on practical UX: fast interactions, resilient data loading, and persistent preferences so users can resume exactly where they left off.

    Features

    • Real-time conversion with live exchange rates
    • Searchable currency selectors with broad coverage
    • Rate and inverse-rate display with friendly feedback
    • Local history, recent choices, and theme persistence
    • Loading states, validation messages, and API fallback

    Built with semantic HTML, modular CSS, and clean vanilla JavaScript.
